# 마크다운 기초

마크다운(Markdown)은 간단한 텍스트 문법으로 서식 있는 문서를 만드는 언어입니다.

## 자주 쓰는 문법

### 제목 (Heading)
```markdown
# 1단계 제목
## 2단계 제목
### 3단계 제목
```

### 텍스트 강조
```markdown
**굵게 (Bold)**
*기울임 (Italic)*
~~취소선~~
`인라인 코드`
```

### 목록
```markdown
- 순서 없는 목록
  - 들여쓰기로 하위 항목

1. 순서 있는 목록
2. 두 번째 항목
```

### 링크와 이미지
```markdown
[링크 텍스트](https://example.com)
![이미지 설명](이미지경로.png)
```

### 표 (Table)
```markdown
| 열1 | 열2 | 열3 |
|-----|-----|-----|
| A   | B   | C   |
```

---

## 전자책 작성 팁

1. 각 챕터는 별도 폴더에 저장 (`chapter1/`, `chapter2/` 등)
2. 챕터 시작 파일은 `README.md`로 이름 지정
3. `SUMMARY.md`에 모든 파일 경로를 등록해야 GitBook에 반영됨
