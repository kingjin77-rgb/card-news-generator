# GitHub 전자책 만들기 가이드

> GitHub와 GitBook/Wikidocs를 활용하여 나만의 전자책을 만드는 완벽 가이드

---

## 이 책에 대하여

이 전자책은 **마크다운(Markdown)** 파일로 내용을 작성하고, **GitBook** 또는 **위키독스(Wikidocs)** 와 연동하여 `.epub` 또는 `.pdf` 형식의 전자책을 만드는 방법을 단계별로 설명합니다.

## 목차

| 장 | 제목 |
|---|---|
| 1장 | [전자책과 GitHub 소개](chapter1/README.md) |
| 2장 | [GitHub 저장소 준비하기](chapter2/README.md) |
| 3장 | [GitBook 연동하기](chapter3/README.md) |
| 4장 | [위키독스 연동하기](chapter4/README.md) |
| 5장 | [전자책 배포 및 출판](chapter5/README.md) |

---

## GitBook 연동 방법

1. [gitbook.com](https://gitbook.com)에서 계정 생성 및 로그인
2. **New Space** 생성
3. **Integrations → GitHub** 연동 → 이 저장소 선택
4. `SUMMARY.md` 기반으로 자동 목차 생성됨
5. 변경사항 push 시 GitBook 자동 반영

## 위키독스 연동 방법

1. [wikidocs.net](https://wikidocs.net) 로그인
2. **나의 책 → 깃허브 책 만들기** 클릭
3. 이 저장소 연결 → `.epub` / `.pdf` 다운로드 가능
