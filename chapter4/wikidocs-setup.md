# 위키독스 설정 방법

## 1단계: 위키독스 계정 생성
1. [wikidocs.net](https://wikidocs.net) 접속
2. **회원가입** 또는 소셜 로그인

## 2단계: GitHub 연동 책 만들기
1. 로그인 후 우측 상단 프로필 → **나의 책**
2. **깃허브 책 만들기** 버튼 클릭
3. GitHub 인증 → 연동할 저장소 선택
4. 브랜치 및 루트 폴더 설정

## 3단계: epub/pdf 다운로드
1. 책 대시보드 → **책 설정**
2. **전자책 만들기** → 형식 선택 (epub / pdf)
3. **생성** 클릭 → 완료 후 다운로드

## 위키독스 활용 팁
- **무료로 epub/pdf 생성** 가능 (GitBook 무료 플랜은 유료)
- 한국어 독자 대상 전자책에 최적화
- 커뮤니티 노출 효과 (위키독스 검색 노출)
- 유료 판매 설정으로 수익화 가능
