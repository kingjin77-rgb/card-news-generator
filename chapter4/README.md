## 위키독스란?

위키독스(Wikidocs)는 국내 대표 전자책 플랫폼으로, GitHub 연동을 통해 마크다운 원고를 `.epub` 및 `.pdf` 형식으로 출판할 수 있습니다.

## GitBook vs 위키독스 비교

| 항목 | GitBook | 위키독스 |
|------|---------|----------|
| 언어 | 영문 중심 | 한국어 특화 |
| 무료 플랜 | 1개 Space | 무제한 |
| epub/pdf | 유료 기능 | **무료 제공** |
| 웹 공개 | 기본 제공 | 기본 제공 |
| 수익화 | 제한적 | 유료 판매 가능 |

> 한국어 전자책이라면 **위키독스**가 더 유리합니다.
