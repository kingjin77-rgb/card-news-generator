## 전자책이란?

전자책(e-book)은 디지털 형태로 배포·열람하는 책입니다.

| 형식 | 특징 |
|------|------|
| `.epub` | 표준 전자책 형식, 리더기 호환성 최고 |
| `.pdf` | 고정 레이아웃, 인쇄 용도에 적합 |
| `.html` | 웹 브라우저에서 바로 읽기 가능 |

## GitHub + 마크다운 방식의 장점

- **버전 관리**: 모든 수정 이력이 자동 저장
- **협업**: 여러 사람이 동시에 집필 가능
- **무료 호스팅**: GitHub Pages로 무료 배포
- **자동화**: push 한 번으로 GitBook 자동 갱신
