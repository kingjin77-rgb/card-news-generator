# GitHub를 활용하는 이유

## 기존 전자책 제작의 문제점

| 방식 | 문제점 |
|------|--------|
| 워드프로세서 | 버전 관리 어려움, 협업 불편 |
| 전용 저작 도구 | 유료, 플랫폼 종속 |
| 블로그 | 목차 구성·배포 형식 제한 |

## GitHub를 선택해야 하는 이유

### 1. 무료 & 오픈소스
GitHub 공개 저장소는 무료이며, GitBook 무료 플랜과 연동 가능합니다.

### 2. 마크다운의 단순함
마크다운은 **텍스트 에디터 하나**로 작성할 수 있습니다.

```markdown
# 제목
## 소제목

**굵게**, *기울임*, `코드`

- 목록 항목 1
- 목록 항목 2
```

### 3. GitBook·Wikidocs 자동 연동
GitHub 저장소에 push하면 GitBook이 자동으로 전자책을 업데이트합니다.

### 4. 다양한 출력 형식
동일한 마크다운 원고로:
- GitBook → 웹 문서
- Wikidocs → `.epub` / `.pdf` 다운로드

## 전체 흐름 요약

```
마크다운 작성 → GitHub push → GitBook/Wikidocs 자동 반영 → epub/pdf 배포
```
